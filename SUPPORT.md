# Support

## How to get help

- **Bugs:** open a [bug report](https://github.com/pookie2006/SoFi-Coach/issues/new?template=bug_report.yml)
- **Ideas:** open a [feature request](https://github.com/pookie2006/SoFi-Coach/issues/new?template=feature_request.yml)
- **Questions:** open a GitHub issue with enough context to reproduce or discuss the topic
- **Security:** follow [SECURITY.md](SECURITY.md) instead of filing a public issue

## What to include

The more detail you provide, the faster we can help: expected vs actual behavior, steps to reproduce, and environment information.
