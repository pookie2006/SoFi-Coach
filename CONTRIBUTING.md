# Contributing to SoFi-Coach

Thanks for helping improve this project. This guide explains how to report bugs, request features, and submit changes.

## Before you start

- Read the [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you agree to follow it.
- Search [existing issues](https://github.com/pookie2006/SoFi-Coach/issues) and pull requests before opening a new one.

## Report a bug

Use the bug report template and include:

- What you expected to happen
- What actually happened
- Steps to reproduce
- Environment details (OS, browser or runtime, version)

## Request a feature

Use the feature request template. Describe the problem, the proposed change, and any alternatives you considered.

## Submit a pull request

1. Fork the repository and create a branch from `main`.
2. Keep the change focused. Prefer small pull requests over large ones.
3. Update docs when behavior or setup changes.
4. Fill out the pull request template and link related issues.
5. Respond to review comments and keep the branch up to date with `main`.

## Development notes

Setup and test commands will be added here as the application code lands. Until then, keep documentation accurate and avoid committing secrets, credentials, or generated artifacts.

## Questions

Open a GitHub issue for project questions that are not security reports. For vulnerabilities, follow [SECURITY.md](SECURITY.md).
