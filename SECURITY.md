# Security Policy

## Supported versions

This project is in early development. Security fixes will be applied to the latest code on `main`.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately through [GitHub Security Advisories](https://github.com/pookie2006/SoFi-Coach/security/advisories/new).

Include:

- A description of the issue
- Steps to reproduce, or a proof of concept if you have one
- Impact, if you know it
- Any suggested fix

We will acknowledge the report as soon as we can, follow up with next steps, and credit reporters who want to be named once a fix is released.

## Safe handling

Do not commit secrets, API keys, tokens, or personal financial data. Use environment variables or a local, untracked config file for credentials.
